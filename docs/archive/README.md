# Documentation archive

This folder holds materials that are not required for normal VX6 use or core development.

- `internal-material/`: proposal drafts and deep technical planning documents; intentionally ignored by Git.
- `reports/`: generated benchmark reports; intentionally ignored by Git.
- `provenance/`: ownership package, snapshots, and history export retained from the original repository.
- `legacy-file-map.md`: superseded file map retained as a reference; use `../repository-map.md` instead.
